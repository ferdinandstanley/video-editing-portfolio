# Stanley Ferdinand — Video Editing Portfolio

Dark cinematic portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — portfolio website
- `styles.css` — responsive styling
- `script.js` — project gallery, filters and video embeds
- `resume.html` — printable video editing resume
- `favicon.png` — optional; add your SF favicon here

## Publish with GitHub Pages
1. Create a new public GitHub repository, e.g. `video-portfolio`.
2. Upload the contents of this folder to the repository root (not the ZIP itself).
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Your site URL will be `https://YOUR-USERNAME.github.io/video-portfolio/`.

## Add your videos
Edit `portfolioConfig` in `script.js`. For each project, update `title`, `category`, `label`, `description`, `software`, `thumbnail`, `videoUrl`, and `year`. Categories: `commercial`, `social`, `storytelling`, `motion`, `youtube`. Add the showreel link to `showreelUrl`.

Supported links: YouTube, Vimeo, Google Drive file links, and public direct MP4/WebM URLs. For Google Drive, set sharing to anyone with the link can view. Large MP4 files should be hosted externally rather than committed to GitHub.

## Suggested project organization
Start with your strongest 6–10 projects: commercial/brand promotions; social media/short-form edits; cinematic storytelling; motion graphics/animation; YouTube/long-form content. Use real work you have permission to show. Add a thumbnail, concise description, your role, software used and working watch link. Do not publish confidential client work without permission.

Review the resume and all software/experience details before publishing. Remove any tool or service you cannot confidently demonstrate.
